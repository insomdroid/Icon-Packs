# Insomdroid Icon Packs

A multi-theme Android icon pack collection with one shared catalog and independently installable theme APKs.

## Themes
- KitKat — faithful Android 4.4-inspired original artwork
- Nothing — original dot/geometric theme
- Holo — Android Holo-inspired original artwork
- Material — original Material-inspired artwork

## Build
Use **Actions → Build Icon Packs → Run workflow** and choose Catalog, one theme, or All.

Minimum SDK: Android 10 (API 29). Compile/Target SDK: 36.

The initial foundation includes the catalog, pack metadata, app-filter resources, and placeholder-free original vector symbols. The icon library will grow as original artwork and verified component mappings are added.
