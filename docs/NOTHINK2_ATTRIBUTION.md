Nothink2 uses artwork and application component mappings from Lawnicons.

- License: Apache License 2.0
- License text: `third_party/lawnicons/LICENSE`

Nothink2 converts Lawnicons SVG artwork into transparent monochrome glyph masks. Classic icon-pack resources place those glyphs on near-black tiles and scale them down; themed-icon resources remain transparent so compatible launchers can apply wallpaper-derived colors and their own icon mask.

Nothink2 is unofficial and is not affiliated with Lawnchair, Lawnicons, or Nothing Technology Limited.
