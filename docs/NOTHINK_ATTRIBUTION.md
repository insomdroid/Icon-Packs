# Nothink Icon Pack — Artwork and Mapping Attribution

Nothink is an independent, unofficial icon pack inspired by the monochrome and geometric visual language of Nothing OS. It is not affiliated with, endorsed by, or sponsored by Nothing Technology Limited. Nothing names and marks remain the property of their respective owner.

## App mapping source

- Project: [Lawnicons](https://github.com/LawnchairLauncher/lawnicons)
- Mapping file only: `app/assets/appfilter.xml`
- Pinned source revision: `cd91ff0bd00ff0a6c9d606d1c326b451b6563506`
- License: Apache License 2.0
- License text: [`third_party/lawnicons/LICENSE`](../third_party/lawnicons/LICENSE)

The build downloads only the pinned `appfilter.xml` mapping file from Lawnicons. It does not download, read, copy, transform, or package Lawnicons SVG files or other upstream icon artwork. Lawnicons is used strictly to obtain Android component-to-icon mappings.

## Original Nothink artwork

All icon illustrations are generated by the Nothink artwork generator in this repository. The generator draws its own geometric frames, letterforms, technical details, and signal-red indicator for each mapped drawable. The visual direction uses a near-black field, restrained white geometry, and a small red accent, with a full-canvas image so compatible launchers can apply their own adaptive icon mask. A separate transparent glyph layer is generated for compatible themed-icon implementations.

The generated illustrations are original Nothink artwork and are not derived from Lawnicons SVGs or Nothing proprietary artwork. The workflow checks that at least 3,000 app component mappings are present before packaging.
